KimTay Pet Store SQL Database Analysis

Project Overview
This project uses SQL to analyze customer information, invoices, and transaction records for the KimTay Pet Store database. It demonstrates how relational databases can be used to retrieve and organize business information.

Technologies Used
- SQL
- Relational Databases

Features
- Retrieves customer and invoice information
- Combines multiple tables using SQL JOIN statements
- Filters records based on account balances and invoice dates
- Sorts customer and transaction information

Skills Demonstrated
- SQL Query Development
- Relational Database Management
- Data Analysis
- Data Filtering and Sorting
- Problem-Solving
